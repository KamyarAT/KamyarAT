# Kamyar

I work on [Madmail](https://github.com/themadorg/madmail), a chatmail relay for [Delta Chat](https://delta.chat/). It is one Rust program a community can run for itself: the mail still moves, the conversations stay encrypted, and people on other relays can still reach each other.

The project is at [madmail.chat](https://madmail.chat). I write the occasional longer note on the [blog](https://madmail.chat/blog).

Based in Munich.
