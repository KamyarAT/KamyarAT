### A little about me

I'm a developer based in Munich, interested in backend systems, networking, and open-source infrastructure. I like building things that are useful, relatively simple to maintain, and don't require handing everything over to a big platform.

I'm part of [the mad org](https://github.com/themadorg), a team working on open-source communication tools. These days, I spend a lot of my time working on [Madmail](https://github.com/themadorg/madmail), a Rust-based Chatmail server for [Delta Chat](https://delta.chat/).

Outside of coding, I'm usually listening to blues, reading science fiction, or finding an excuse to tinker with some old hardware.

### What I'm working on

**[Madmail](https://github.com/themadorg/madmail)**

Madmail makes it easier to run your own Chatmail relay. It's built in Rust, comes as a single binary, and lets individuals and communities host their own messaging infrastructure while staying connected to the wider Delta Chat network.

I'm particularly interested in making self-hosted communication more accessible, reliable, and resilient on difficult networks.
